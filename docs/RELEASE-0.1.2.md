本轮落实上一轮独立审查提出的两项迭代：

1. 单一诊断映射 `scripts/diagnostics.zh.json` 同时驱动中文解释与入门表格。`check_diagnostics.mjs --write` 更新表格；不带参数检查一致性。CI 从非测试 MoonBit 源中的字面量 issue 调用和 JSON code 属性提取23种代码，检查中文标题和建议，并反向验证删除映射、新增未知码会失败。动态 issue 代码将要求显式扩展检查器。此检查是当前源代码约定下的静态防护，不是通用 MoonBit 语法分析器。
2. 固定 header 坏包加入样例；教程的19个 shell 命令块实际执行，覆盖检查、导出及四类“失败→复制修复→成功”过程，校验退出码，核对源样例摘要未变。临时副本在测试结束清理。

核心 API 和 JSON CLI 未改，未知代码仍显示原代码和原因并明确失败，不会误报成功。本轮不扩展标准兼容范围。
